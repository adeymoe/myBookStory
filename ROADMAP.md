# Roadmap

Things I plan to work on as I continue developing MyBookStory.

## Store Improvements
- Add better book search and filtering options.
- Allow users to browse books by category and author.
- Improve the book details page.
- Add book reviews and ratings.

## Orders and Payments
- Improve order tracking and delivery updates.
- Add email notifications when an order is placed or updated.
- Improve payment failure handling and transaction records.
- Make the checkout process smoother.

## Admin Dashboard
- Add an admin dashboard for managing books and categories.
- Allow admins to update stock and book prices.
- Add basic sales and order statistics.
- Improve order and delivery management.

## User Experience
- Improve the mobile layout.
- Add a wishlist so users can save books for later.
- Make account and order history management easier.

## Future Ideas
- Add book recommendations based on user interests.
- Introduce discount codes and promotional offers.
- Explore SMS notifications for order updates.
